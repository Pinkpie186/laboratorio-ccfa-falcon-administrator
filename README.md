# Laboratório CCFA Falcon Administrator

Aplicação responsiva e offline, em português, para preparação ao CrowdStrike Certified Falcon Administrator (CCFA).

## Uso

Abra `index.html` ou acesse a publicação no GitHub Pages. Progresso, materiais importados e calendário permanecem no navegador de cada usuário por IndexedDB, com `localStorage` somente como cache/fallback.

## Segurança

- Não registre CID, tokens, Client ID/Secret, hostname, IP ou dados do tenant.
- Execute os laboratórios somente em tenant ou VM de teste autorizados.
- Não envie materiais a serviços externos sem autorização.
- A aplicação não contém credenciais nem backend embutido.

## Fontes

As referências e links oficiais da CrowdStrike estão disponíveis na aba **Documentação** da aplicação.
